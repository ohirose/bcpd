# MERFISH demo data

These files contain cell-centroid coordinates and sparse log-expression
profiles for the three representative source-target pairs in the DET paper's
MERFISH qualitative figure:

- anterior: Zhuang-ABCA-1.008 to Zhuang-ABCA-1.009
- middle: Zhuang-ABCA-1.087 to Zhuang-ABCA-1.088
- posterior: Zhuang-ABCA-1.140 to Zhuang-ABCA-1.141

The data were derived from the Allen Brain Cell Atlas Zhuang-ABCA-1 MERFISH
dataset. The demo fits a separate 50-dimensional PCA representation to each
pair; it does not reuse the paper experiment's global PCA basis.

Dataset source: <https://alleninstitute.github.io/abc_atlas_access/descriptions/Zhuang-ABCA-1.html>
